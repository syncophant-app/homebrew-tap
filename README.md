# Syncophant Homebrew Tap

```sh
brew install --cask syncophant-app/tap/syncophant
```

To use the short name `brew install --cask syncophant`, tap and trust this repository first:

```sh
brew tap syncophant-app/tap
brew trust syncophant-app/tap
```

The cask is updated automatically when a new version of [Syncophant](https://github.com/syncophant-app/macos) is released.
